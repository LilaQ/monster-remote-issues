# Monster Remote Support

For help with Monster Remote, contact **info@emudev.de**.

Include your iOS or Android app version, Gym Monster model, machine software version, and a brief description of the problem. Never send passwords, pairing codes, access keys, or payment details. Remove personal information from any screenshots or logs before sharing them.

Monster Remote requires a supported Gym Monster and a connection to the same local network. Check **Settings → GM Compatibility** for your installed machine version. Use the app's setup and Helper update screens when prompted.

Purchases can be restored through the app. Apple or Google manage store billing and subscriptions. Optional cloud account deletion is available in the app's account settings; contact the support address above if you need assistance.

Monster Remote is an unofficial companion app and is not affiliated with, endorsed by, or sponsored by Speediance.
